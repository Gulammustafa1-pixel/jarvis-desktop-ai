# 🤖 Jarvis Desktop AI Assistant

An AI-powered desktop voice assistant built with Python that responds to the wake word **"Hey Jarvis"** and performs hands-free desktop automation. The assistant runs in the background, listens for voice commands, and provides intelligent spoken responses using Ollama.

---

## 🚀 Features

- 🎙️ Wake Word Detection ("Hey Jarvis")
- 🤖 AI-powered conversations with Ollama
- 🗣️ Speech Recognition
- 🔊 Natural Text-to-Speech Responses
- 🌐 Open Chrome, GitHub, YouTube, LinkedIn, and other applications
- 📂 Open Desktop, Downloads, Documents, and system folders
- 🔍 Perform Google searches using voice commands
- 📁 Create folders through voice interaction
- ⚡ Background voice assistant service
- 💻 Automatic startup support on Windows
- 🧠 Modular architecture for easy feature expansion

---

## 🛠️ Tech Stack

- Python
- OpenWakeWord
- Ollama
- SpeechRecognition
- PyAudio
- pyttsx3
- NumPy
- ONNX Runtime
